# Employee Attrition Analysis

**HCLTech Career Shaper Project**

## Project Overview
This project analyses employee attrition using Python, SQL and Power BI. It identifies patterns and factors associated with employees leaving an organisation.

## Tools and Technologies
- Python (Pandas, Matplotlib, Seaborn)
- SQL
- Power BI
- Google Colab

## Dataset
IBM HR Analytics Employee Attrition Dataset containing 1,470 employee records.

## Project Files
- Python analysis notebook
- Cleaned employee dataset
- SQL queries
- Power BI dashboard
- Project report

## Key Findings
- Total Employees: 1,470
- Employees Left: 237
- Overall Attrition Rate: 16.12%
